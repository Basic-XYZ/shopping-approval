# 配置与联调

## 账号和环境

1. 微信公众平台「开发管理 → 开发设置」获取自己的 AppID，填入 `project.config.json`。不需要将 AppSecret 放入仓库或聊天。
2. 在微信开发者工具中确认该小程序可访问 CloudBase 环境 `basic-d0g7ij3x16f8cdbb6`。当前它是已登录腾讯云账号下的环境，**尚未核实小程序关联**。若未关联，先按控制台指引完成关联；不要盲目替换成他人的环境。
3. 前端环境配置在 `miniprogram/config.js`。此 ID 不是密钥。
4. `npm run check:deployment` 检查本地 AppID 格式。通过仅代表本地配置完整，不能证明账号权限或环境关联正确。

## 后端部署前置条件

先确认目标确为开发环境，并核查体验版剩余期限、配额和超额计费设置。本项目不自动购买、续费或创建环境。

CloudBase 文档数据库创建 `cloudbase/database.json` 列出的四个集合。对每个集合应用自定义权限：

```json
{ "read": false, "write": false }
```

客户端不能直接访问数据库；所有操作经过云函数。**仓库中的 JSON 是配置清单，不会自动应用到云端。** 同时创建清单内的索引。若平台自动包含 `_id`，按控制台支持方式核对索引字段，不要跳过真实列表查询验证。

部署 `cloudfunctions/shoppingApi` 为事件云函数，入口 `index.main`，建议 Nodejs18.15 或平台支持的更高兼容版本，超时 20 秒。部署前在该目录执行 `npm ci --ignore-scripts`；核对部署工具是否使用锁文件安装依赖。

云函数环境变量：

```text
MINIPROGRAM_APPID=自己的微信小程序AppID
```

缺少该变量时函数明确拒绝服务。不要开放匿名 HTTP 网关，不需要为此申请域名或配置 CORS。函数访问权限按小程序调用场景配置，入口还会校验真实 `APPID` 和 `OPENID`。

可以通过微信开发者工具上传云函数；若用 CloudBase CLI，先运行 `tcb fn --help` 和相关子命令帮助核实当前版本用法，再指定环境及函数目录。不要在未知目录直接执行全量部署。

## 双人验收

1. 开发者工具导入根目录、配置真实 AppID、编译。确认没有模板或 JS 报错。
2. 两个微信账号均进入小程序，分别保存昵称。预览前按微信要求将测试账号加入开发/体验成员。
3. A 生成邀请码，通过小程序分享或复制给 B，B 主动确认绑定。双方应显示彼此昵称。
4. A 提交申请，B 在「待我审批」看见申请。A 无权审批自己的申请。
5. B 驳回并填写理由，A 修改重提；B 同意后，A 标记已购买。
6. 快速重复点击、网络超时重试，不应生成重复申请或覆盖已有审批。
7. C 未绑定时不应读取 A/B 申请。A/B 解绑后，旧申请详情和审批均不可访问。
8. 重新绑定同一搭档开启新关系，不恢复旧关系记录。验证真实事务冲突行为。

本版通过下拉刷新获取新申请，无后台订阅推送。准备上线时再根据 AppID 配置订阅模板、隐私保护指引、内容安全和审核要求。
